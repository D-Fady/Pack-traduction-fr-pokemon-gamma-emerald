# Pack-traduction-fr-pokemon-gamma-emerald
C'est un correctif qui permet de traduire le jeu Pokémon Gamma Emerald en français pour la version 1.11.0. Il est baser sur la traduction officielle de Pokémon émeraude.
Pour que le correctif fonctionne, il suffit simplement de le placer PokemonEmerald-Windows_FR_P.pak dans le répertoire PokemonEmerald\Content\Paks\ puis de lancer le jeu. Vous pouvez aussi juste glisser-déposer le dossier que vous téléchargez.

## Point IMPORTANT
Le jeu choisit sa langue d'après celle de Windows. Si votre Windows est en anglais, il verra le jeu en anglais. Dans ce cas, vous pouvez forcer le français :
   - faite un clic droit sur le raccourci du jeu, puis Propriétés ;
   - dans Cible, ajoutez  -culture=fr après le chemin, en gardant l'espace avant le tiret, par exemple : "...\PokemonEmerald.exe" -culture=fr
Certain texte n'on pas été traduit pour ne pas perturber le fonctionnement du jeu et certain texte peut être hors champ (sortir de la zone de texte habituelle).
